# CNC Mill (Ibuki)

[<img class="equipment-thumbnail" src="./images/overview.jpg" alt="Laser cutter overview">](./images/overview.jpg)

A Isel GFM 4433 that we aquired with a faulty control system.
Upgraded with a [RP23CNC](https://github.com/phil-barrett/RP23CNC).

It has a usable bed size of approximately 500x350mm.

## Essential Information

- Location: Ground Floor Corridor
- Responsible Person(s): Dan Nixon
- Induction Required: Yes

## Induction checklist

- Turning on machine with fob
- Panel controls
- gSender setup
    - jogging
    - axis zero
    - any machine specific gcode
- Clamping options
- Changing tools
- Turning off machine
- The need to keep the machine tidy
